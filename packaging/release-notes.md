## Download

| Your computer | File |
|---|---|
| Windows 10 / 11 | `PixSift-windows.zip` |
| Mac with Apple silicon (M1 or later) | `PixSift-mac-arm64.zip` |
| Mac with Intel processor | `PixSift-mac-intel.zip` |

Not sure which Mac you have? Apple menu → **About This Mac**: "Chip: Apple M…" means Apple silicon.

## Install

These builds aren't signed yet, so the first launch shows a security prompt.

- **Mac:** unzip, move **PixSift** to Applications and open it. When macOS says it can't verify the developer,
  open **System Settings → Privacy & Security**, scroll down, click **Open Anyway** and confirm.
- **Windows:** unzip the whole folder, open it and run **PixSift.exe**. If SmartScreen appears, click
  **More info → Run anyway**.

The first scan downloads the on-device AI models once (about 195 MB). After that, PixSift works offline and
nothing leaves your computer.

Testing PixSift? See the [testing guide](https://github.com/jha-pravin/pixsift/blob/main/TESTING.md).
